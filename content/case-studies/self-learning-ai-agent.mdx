## Problem

Most student "AI agents" are static: they prompt an LLM with fixed instructions and behave the same on day 1 and day 100. Chat history and better prompts are **not learning**. The goal was an agent whose **policy actually changes from experience**, with proof that it improved.

## Data

There's no fixed dataset. The agent generates its own experience as `(state, action, reward, next_state)` transitions by interacting with two Gymnasium environments: **FrozenLake-v1** (tabular) and **CartPole-v1** (continuous state).

## Approach

- **Tabular Q-learning** on FrozenLake, checked against a worked example done by hand in a unit test.
- **Deep Q-Network written from scratch in PyTorch** (no Stable-Baselines3): experience replay, a target network, Huber loss and gradient clipping. Truncation at the time limit is treated correctly as non-terminal.
- **Evaluation protocol:** frozen-policy evaluation (ε = 0), separate training, validation and test seeds, before/after comparison on the same test seeds, comparison with a random baseline (Welch's t-test + bootstrap 95% CI over 5 seeds), and a checkpoint-persistence test.
- **Ablation:** full DQN vs no replay vs no target network.
- Runs are tracked in SQLite and shown in a Streamlit dashboard, where an LLM explains the learned behaviour using the logged numbers.

## Result

Numbers from the experiment database behind the [live dashboard](https://self-learning-ai-agent-final-year-project.streamlit.app/):

- **Held-out test score: 500.00.** That's the mean return of the frozen DQN policy (ε = 0) on unseen test seeds for CartPole-v1, seed 4. 500 is the maximum possible, because episodes are capped at 500 steps.
- **Learning is visible in training itself:** average reward rose from **20.77** over the first 120 episodes to **398.30** over the last 120 of that run. Over its last 50 training episodes (ε > 0, so still exploring), it averaged **394.74**.
- **Scale:** **36 training runs** (31 completed, 0 failed) and **20,314 episodes** logged across 3 experiments.
